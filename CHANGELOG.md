# CHANGELOG

## 1.0.0 (в разработке)

- Исправлено: `Bundle-ActivationPolicy: lazy` — бандл активируется при первом
  обращении (иначе страница настроек и обработчики падали с NPE при `getDefault()`).
- Страница настроек больше не зависит от активатора (`ScopedPreferenceStore`).

- M0: каркас бандла `ru.citcer.uuidcheck`, точки расширения, target-платформа
  на EDT 2025.1 и 2026.2.
- M1: StAX-парсер `UuidXmlParser`, `MdoUuidScanner`, фикстуры и unit-тесты.
- M2: индекс `ProjectUuidIndex`, `DuplicateAnalyzer`, кэш `PersistedIndexStore`
  (JSON, схема 1), экспорт CSV/отчёта; эталонные экспорты
  совпадают побайтово на реальном проекте.
- M3: маркеры Problems (`persistent=false`, лимит, сводный маркер).
- M4: view «Дубли UUID» с фильтром, сортировкой, навигацией и экспортом;
  группа раскрывается в полный список файлов (двойной клик по группе), кнопки
  «Развернуть всё / Свернуть всё».
- M5: `UuidResourceChangeListener`, debounce-планировщик, инкрементальный скан
  по кэшу, проектные настройки.
- M6: страницы настроек, NLS (RU), логирование.
- Ручная команда «Проверить дубликаты UUID» работает и при выключенном
  автоскане проекта.
- Реализованы настройки «Помечать маркером неразобранные файлы» и
  «Показывать диалог о новых дублях».
